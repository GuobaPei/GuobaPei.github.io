# guobapei.github.io

Personal academic homepage of **Jieyuan Pei (裴杰远)** — Zhejiang University of Technology
(浙江工业大学, ZJUT), Hangzhou.

Live at <https://guobapei.github.io/>

A single static page, no build step and no framework: `index.html` carries all its
own CSS, and the only external request is the Google Fonts stylesheet.

```
index.html      the whole page
me.jpg          photo
figs/           one representative figure per paper
logos/          competition logos
```

Editing: change `index.html`, commit, push. GitHub Pages redeploys on every push to `main`.
